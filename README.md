# 📊 Student Performance Analysis using Python

## 📌 Project Overview
This project focuses on analyzing student performance data to identify key factors affecting academic results. The analysis helps in understanding trends and patterns in student scores using data analytics techniques.

---

## 🎯 Objectives
- Analyze student scores in Math, Reading, and Writing  
- Identify performance differences based on gender  
- Understand the impact of parental education  
- Explore factors affecting student performance  

---

## 🛠 Tools & Technologies
- Python  
- Pandas  
- Matplotlib  
- Google Colab  

---

## 📂 Dataset Information
The dataset contains the following features:
- Gender  
- Race/Ethnicity  
- Parental Level of Education  
- Lunch  
- Test Preparation Course  
- Math Score  
- Reading Score  
- Writing Score  

---

## 📊 Analysis Performed
- Data cleaning and preprocessing  
- Exploratory Data Analysis (EDA)  
- Gender-based performance comparison  
- Parental education impact analysis  
- Visualization using charts  

---

## 📈 Key Insights
- Male students perform better in math on average  
- Female students excel in reading and writing  
- Higher parental education leads to better student performance  
- Students with standard lunch perform better  
- Most students score between 60–80
